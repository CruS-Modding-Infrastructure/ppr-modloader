# PPR Utilities - Документация
Языки: [English](/docs/EN/main.md) / [Русский](/docs/RU/main.md)  
Версия документации: v0.2

PPR Utilities - это встроенный в загрузчик модов API для игры Psycho Patrol R

Задача данного API упростить для создателей модов взаимодействие с миром игры и обеспечить совместимость модов между собой

PPR Utilities имеет модульную структуру, каждый модуль отвечает за определённую механику игры, такие как уровни, оружие, новые вкладки для меню
