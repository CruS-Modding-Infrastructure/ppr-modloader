PPR Utilities - this is the built-in API for the game Psycho Patrol R

The purpose of this API is to make it easier for mod creators to interact with the game world and ensure that mods are compatible with each other

PPR Utilities has a modular structure, each module is responsible for specific game mechanics, such as levels, weapons, new tabs for menus
