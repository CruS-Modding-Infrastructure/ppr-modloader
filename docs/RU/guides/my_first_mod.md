# Это всё хорошо, но с чего мне начать?

Первым делом нужно декомпилировать Psycho Patrol R
На данном этапе мы получим скрипты, текстуры и модели игры с которыми будем работать

Для этого используется программа Godot RE Tools

Далее скачиваем PPR Modloader и переносим папки **addons** и **PPR_Utilities** в папку с декомпилированным Psycho Patrol R

Открываем **project.godot** в любом удобном для вас текстовом редакторе, ищем строку `[autoload]` и под ним вставляем данные строчки:

```
PPRUtilities="*res://PPR_Utilities/init.tscn"
ModLoaderStore="*res://addons/mod_loader/mod_loader_store.gd"
ModLoader="*res://addons/mod_loader/mod_loader.gd"
```

Закрываем и сохраняем **project.godot**

Запускаем Godot v3.6

Нажимаем кнопку `Import` и ищем декомпилированный Psycho Patrol R

После чего мы можем открывать проект и начать создание модов
