# Основы PPR Utilities
[Назад](/docs/RU/main.md)

PPR Utilities представляет собой обёртку которая облегчает вам работу с внутриигровыми механиками позволяя создавать разные прикольные штуки (Можно сказать что всю грязную работу сделали уже за вас)

Всю информацию о модулях можно найти на главной странице документации
# Как мне воспользоваться PPR Utilities? 

Очень просто
Обычно обращение к модулям выглядит вот так:

```python
PPRUtilities.[название модуля].[название функции]

PPRUtilities.main_menu.add_menu(...)
PPRUtilities.locations.add_location(...)
PPRUtilities.weapons.add_weapon(...)
#etc. etc.
```

Более подробно о функциях модуля указано на его странице
