Данный модуль позволяет создавать свои вкладки в главном меню
# Методы

`add_menu(menu_name : String, menu_node_path : String) -> void`  
Добавляет новую вкладку в главное меню  
menu_name - Название вкладки  
menu_node_path - Путь до сцены где находится вкладка
