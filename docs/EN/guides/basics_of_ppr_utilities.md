# Basics of PPR Utilities
[Back](/docs/EN/main.md)

PPR Utilities is a wrapper that makes it easier for you to work with in-game mechanics, allowing you to create all sorts of cool things (I can say that all the dirty work has already been done for you)

All information about the modules can be found on the main documentation page
# How do I use PPR Utilities?

Very simple 
Usually, accessing modules looks like this:

```python
PPRUtilities.[Module Name].[Method Name]()

PPRUtilities.main_menu.add_menu(...)
PPRUtilities.locations.add_location(...)
PPRUtilities.weapons.add_weapon(...)
#etc. etc.
```

More details about the methods of the module are described on its page
